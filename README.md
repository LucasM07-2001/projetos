# Projetos de estudo — JavaScript

Repositório com meus exercícios e estudos de lógica de programação e JavaScript, executados com Node.js.

## 📁 Estrutura

```
javascript/
├── javascript-basico/        # fundamentos da linguagem
└── logica-de-programacao/    # exercícios de lógica
```

## 🛠️ Tecnologias

- JavaScript (ES6+)
- Node.js

## ▶️ Como rodar

```bash
git clone https://github.com/LucasM07-2001/projetos.git
cd projetos
npm install
node javascript/<pasta>/<arquivo>.js
```
